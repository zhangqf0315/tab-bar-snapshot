# 标签栏快照

一个 Chrome / Edge 浏览器插件，用来把当前窗口打开的标签页保存成“快照文件夹”。适合在关机、重启、临时切换任务前保存当前浏览状态。

## 功能

- 读取浏览器所有普通窗口里的标签页
- 保存前手动取消勾选不需要的标签
- 使用当前日期时间自动命名快照文件夹
- 支持输入自定义文件夹名称
- 保存多个快照文件夹
- 一键把某个快照里的网页重新打开
- 删除不再需要的快照

## 本地安装

1. 打开 Chrome 或 Edge。
2. 进入扩展管理页面：
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
3. 打开“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择当前文件夹：`标签栏快照`。
6. 点击浏览器工具栏里的“标签栏快照”图标开始使用。

## 数据保存位置

快照保存在浏览器扩展的本地存储 `chrome.storage.local` 中。卸载插件或清除浏览器扩展数据会删除这些快照。

## 当前版本限制

- 当前只保存 `http` 和 `https` 网页。
- 恢复快照时会把网页打开为新的后台标签。
- 数据没有同步到云端，换浏览器或换设备不会自动带过去。
